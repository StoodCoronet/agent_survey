# Reference Projects

This directory contains third-party reference projects used for learning, borrowing ideas, or comparing implementation strategies.

Only this `README.md` is tracked in git. The actual project clones are **not** committed — please keep them local.

---

## How to add a reference

```bash
cd reference
git clone <repository-url>
```

Then add a one-line description below so the project is documented.

---

## Current references

- **openreview_downloader** — `https://github.com/mireklzicar/openreview_downloader.git`
  Utility for downloading papers from OpenReview venues (ICLR, ICML, NeurIPS, etc.).
